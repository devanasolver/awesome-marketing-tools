## How to choose

- **Respect privacy law.** Email and tracking tools need consent in many countries (GDPR, CAN-SPAM).
- **Self-hosting email is hard.** Deliverability needs proper DNS and a clean sending reputation.
- **Check the license.** Some analytics tools are source-available with limits.
- **Measure one thing first.** Add tools only when a question needs them.
